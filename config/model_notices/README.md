# Model presentation notices

These are exact presentation snapshots of the six current model records' four
distinct notice texts. File names are their SHA-256 digests; the UI verifies
each against the selected packaged catalog requirement before rendering it.
All original copyright and license text is retained. The catalog's original
source/revision supplies provenance, not this directory or a local receipt.

The EnCodec 24 kHz notice records user supply and the existing no-redistribution
determination. It is not the separate Meta MIT text used by the 48 kHz record.
The Apache-2.0 text retains Alibaba Cloud's copyright for the three Qwen rows;
the Whisper MIT text retains OpenAI's copyright. Do not apply one model's terms
to another or infer model redistribution authority from the host's code license.

This directory contains no model input, graph, codebook or learned parameter.
Copying notices into the host does not create an installation decision or
receipt. Changed requirements need their own exact text and new presentation.
